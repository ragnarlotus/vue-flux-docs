# Components

| Name                                         | Description                                                                                              |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [VueFlux](vue-flux/)               | The main slider component. Check the [complements](../complements/) that you can use to extend functionality |
| [FluxButton](flux-button/)         | Component used to display svg buttons                                                                    |
| [FluxCube](flux-cube/)             | Component capable to display a cube (6 sides) of resources                                               |
| [FluxGrid](flux-grid/)             | Component that divides a resource into blocks                                                            |
| [FluxImage](flux-image/)           | The most basic component that displays an image resource                                                 |
| [FluxParallax](flux-parallax/)     | Makes a resource move in concordance of page scroll                                                      |
| [FluxTransition](flux-transition/) | This is the component in charge of running a transition from a resource to another                       |
| [FluxVortex](flux-vortex/)         | Component that displays a resource in a set of nested circles                                            |
| [FluxWrapper](flux-wrapper/)       | Just a wrapper to easy some transitions                                                                  |
