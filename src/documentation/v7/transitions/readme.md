# Transitions

VueFlux comes with nice 20 transitions.

| Name                               | Component  | Description                                                                                          |
| ---------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------- |
| [blinds2d](blinds2d/)   | Blinds2d   | Divides the image in vertical bars that blinds and fades out                                         |
| [blinds3d](blinds3d/)   | Blinds3d   | Divides the image in vertical bars that blinds 180 deg to form the next image                        |
| [blocks1](blocks1/)     | Blocks1    | The image is split in blocks that shrink and fade out randomly                                       |
| [blocks2](blocks2/)     | Blocks2    | The image is split in blocks that shrink and fade out in wave from a corner to the opposite          |
| [book](book/)           | Book       | Makes the effect of turning a page to display next image                                             |
| [camera](camera/)       | Camera     | From outside to inside the image is being cropped like in a camera lens                              |
| [concentric](camera/)   | Concentric | A concentric effect is performed by rotating the image converted into circles                        |
| [cube](cube/)           | Cube       | Turns the image to a side like if place in a cube                                                    |
| [explode](explode/)     | Explode    | The image is split in blocks that explode revealing the next image                                   |
| [fade](fade/)           | Fade       | Fades from one image to next                                                                         |
| [fall](fall/)           | Fall       | The image falls in front displaying next image                                                       |
| [kenburn](kenburn/)     | Kenburn    | Fades, zoom and moves current image to next                                                          |
| [round1](round1/)       | Round1     | The image is split in blocks that turn 180 deg horizontally to form next image                       |
| [round2](round2/)        | Round2     | The image is split in blocks that round vertically until disappear                                   |
| [slide](slide/)         | Slide      | Slides the image horizontally revealing the next                                                     |
| [swipe](swipe/)         | Swipe      | Swipes the image to display next like uncovered with a curtain                                       |
| [warp](warp/)           | Warp       | A concentric effect is performed by rotating the image converted into circles in alternate direction |
| [waterfall](waterfall/) | Waterfall  | Divides the image in bars and drops them down in turns                                               |
| [wave](wave/)           | Wave       | Makes the image 3D and divides it in slices that turn vertically to display the next image           |
| [zip](zip/)             | Zip        | Divides the image in bars and slides them up and down alternately like a zip                         |
